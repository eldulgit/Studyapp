# StudyApp

사용자의 생활 패턴과 고정 일정을 기반으로 학습 가능한 시간을 분석하여  
공부 일정을 추천하고, 학습 시간과 목표, 집중도를 관리할 수 있는 Android 애플리케이션입니다.

## 프로젝트 기간

- 2025.12 ~ 2026.06
- 팀 프로젝트 / 3인

## 기술 스택

- Kotlin
- Android
- Git
- Gradle

## 담당 역할

- 과목별 공부 타이머 기능 구현
- 목표 시간 설정 및 학습 시간 기록 기능 구현
- 공부 기록 통계 화면 구현
- 프로젝트 초기 기능 정의 및 역할 분담 참여
- 팀 진행 상황 공유 및 일정 조율

## 주요 기능

| 기능 | 설명 |
|---|---|
| 자동 공부 스케줄 생성 | 사용자의 생활 패턴과 고정 일정을 기반으로 공부 가능한 시간 추천 |
| 과목별 공부 타이머 | 과목별 학습 시간 측정 |
| 학습 시간 기록 | 공부한 시간 저장 및 관리 |
| 공부 통계 분석 | 학습 기록 기반 통계 화면 제공 |
| 카메라 기반 집중도 감지 | 학습 중 집중도 측정 기능 제공 |

## 협업 경험

- Git 저장소 구축 및 형상 관리
- 기능별 브랜치 생성 후 개발 진행
- 주기적인 Merge를 통한 코드 통합
- 동일 파일 수정으로 발생한 Merge 충돌 해결
- 팀 진행 상황 공유 및 일정 조율

## 문제 해결 경험

### 문제
공부 타이머 사용 중 카메라 기반 집중도 측정 화면으로 이동했을 때  
타이머가 계속 동작하는 문제가 발생했습니다.

### 해결
화면 전환 시 타이머 상태를 관리하도록 로직을 수정했습니다.  
또한 집중도 측정 기능과 타이머 기능의 상태를 분리하여 처리해  
각 기능이 독립적으로 동작하도록 개선했습니다.
